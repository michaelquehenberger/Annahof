# HTML & CSS – Übungen

Übungsprojekt für HTML (später CSS), bearbeitet mit VSCodium.
https://michaelquehenberger.github.io/Annahof/

## Ordnerstruktur

```
index.html        Startseite
uebungen/         eine Unterordner pro Übung
bilder/           Bilder für die Seiten
```

## Arbeiten in VSCodium

1. **Datei → Ordner öffnen** und diesen Projektordner wählen.
2. Erweiterung **Live Server** installieren (Erweiterungen-Symbol links, "Live Server" suchen).
3. Rechtsklick auf `index.html` → **Open with Live Server**. Beim Speichern lädt der Browser automatisch neu.
4. Tipp: In einer leeren `.html`-Datei `!` tippen und Tab drücken → HTML-Grundgerüst wird eingefügt.

## Regeln

- Dateinamen klein, ohne Leerzeichen und Umlaute (`ueber-mich.html`, nicht `Über Mich.html`).
- Jede Seite beginnt mit `<!DOCTYPE html>` und hat `lang="de"` und `charset="UTF-8"`.
- Jedes geöffnete Tag wird wieder geschlossen (Ausnahmen: `<br>`, `<img>`, `<meta>`).
